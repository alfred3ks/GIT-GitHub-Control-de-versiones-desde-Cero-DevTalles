### Introducción de Git:

Git no es GitHub, con Git controlamos secciones de nuestro repo en nuestro pc, y GitHub es un sistema en la nube.

En esta sección vamos a dar nuestros primeros pasos con Git: entender para qué sirve un control de versiones, aprender los comandos básicos, crear un repositorio y trabajar con el flujo normal de cambios y su historial.

Claro. La diferencia fundamental es esta:

- Git → es un sistema de control de versiones. Se instala en tu ordenador y sirve para guardar el historial de cambios de un proyecto. Te permite, por ejemplo, volver a una versión anterior, crear ramas o comparar cambios.

- GitHub → es una plataforma online donde puedes almacenar repositorios Git y trabajar con ellos desde Internet. Además permite colaborar con otras personas, revisar código, gestionar proyectos, etc.
  Una forma sencilla de verlo:
  Imagina que estás haciendo una aplicación:

Git = el sistema que guarda todas las versiones de tu proyecto.
GitHub = el sitio de Internet donde puedes guardar y compartir ese proyecto.
